# Hello Login Spec Kit

Next.js registration flow for a virtual wallet.

## Stack

- Next.js App Router
- React
- Tailwind CSS
- TypeScript

## Scripts

```bash
npm install
npm run dev
npm run build
npm run test
npm run typecheck
```

## Flow

- `/` redirects to `/register`
- `/register` shows the registration screen
- `/login` shows the hardcoded demo login entry point
- `/construction` is protected and only available after simulated authentication
